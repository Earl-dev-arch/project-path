HOW IT WORKS

A journey, not a personality label.

Each session draws 20 questions from a weighted bank of 1,000. The selection is designed to cover different dimensions instead of asking the same kind of question twenty times.

01

Deep questions

Scenarios, ranking, scales, multiple choice and reflection prompts.

02

Pattern analysis

Looks for repeated signals, contradictions and uncertainty.

03

Several pathways

Shows plausible directions with reasoning, skills and trade-offs.

04

Action roadmap

Turns a pathway into practical next steps based on grade.

NO FAKE PRECISION

No “97% career match.”

Selection probabilities only control which questions appear. They are not psychological probabilities and they never become a “career score.”

PRIVACY NOTICE

What this prototype stores.

Profile, questionnaire and feedback data are stored in browser local storage. Do not enter sensitive real student information into this demo.

Before launch

  • Use server-side sessions or a vetted authentication provider.
  • Encrypt data in transit and at rest; minimize collection.
  • Use role-based access controls and audit logs.
  • Implement age/consent requirements for every country served.
  • Document retention, deletion and correction procedures.
  • Keep AI provider keys on the server and document model-data retention.
  • Use aggregated analytics rather than exposing identifiable student records.
Your Path uses browser storage.

This prototype uses local storage for login state, questionnaire progress and cookie preference.
